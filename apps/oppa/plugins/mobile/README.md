# tauri-plugin-oppa-mobile

Minimal Android and iOS runtime bridge for the OPPA Tauri host.

## Purpose

The shared Rust agent (`oppa-agent` and the `oppa-*` crates) owns
authentication, transport, storage, rendering, printing, job durability, and
deduplication on every platform. This plugin exposes only the capabilities
that are reachable exclusively through the mobile runtimes, so the native
Kotlin and Swift code stays small and free of business logic.

## Responsibilities

| Capability | Android (Kotlin) | iOS (Swift) |
| --- | --- | --- |
| Secure credentials | `AndroidKeystoreCredentialStore`: AES-256-GCM with a non-exportable Android Keystore key; ciphertext only, in backup-excluded preferences | Not needed: `oppa_platform::AppleKeychainCredentialStore` (Rust) |
| Background operation | `AgentForegroundService` (`connectedDevice` type) with a persistent notification and a Stop action; partial wake lock and Wi-Fi lock while running | Bounded `beginBackgroundTask` time for in-flight jobs; optional keep-awake |
| Lifecycle events | Activity availability, foreground/background, default-network changes | Foreground/background, `NWPathMonitor` changes |
| Printer discovery | `NsdManager` DNS-SD browse and resolve | `NWBrowser` Bonjour browse and resolve |
| Permissions | Notifications, battery-optimization exemption, app settings | Local network privacy probe, app settings |
| Updates | Verified hand-off of a downloaded APK to the system installer (package name, newer version code, and signing certificates must match) | None (App Store distribution later) |

Native code delivers events through a Rust-owned Tauri channel. That path is
independent of the WebView and of any Android activity, so the agent keeps
receiving lifecycle and Stop events while it runs in the foreground service.

## Non-responsibilities

- No frontend commands: every native call originates in the Rust host. The
  plugin's command list (`build.rs`) is intentionally empty.
- No agent logic, protocol handling, rendering, or printer I/O.
- No USB or Bluetooth printing.
- No audio, location, VoIP, or other unrelated background modes on iOS.

## Rust API

- `init()`: registers the plugin. The host registers it only on mobile.
- `OppaMobile` (via `OppaMobileExt::oppa_mobile()`): typed native calls with
  explicit deadlines, `subscribe()` for `MobileEvent`s, and `is_attached()`.
- `AndroidKeystoreCredentialStore`: implements
  `oppa_platform::CredentialStore`. Secrets are cached in zeroizing process
  memory after first use, because Android dispatches plugin calls through an
  activity and the agent must re-authenticate from the foreground service
  after the activity is destroyed.

## Dependency role

Depends on `tauri`, `oppa-platform` (for `CredentialStore`), and `tokio`. Only
`apps/oppa/src-tauri` depends on it, through a mobile-only target dependency.
No `crates/oppa-*` crate depends on it.

## Commands

```bash
cargo test -p tauri-plugin-oppa-mobile           # model and event tests on any host
cargo check -p oppa --target aarch64-linux-android  # requires the Android NDK
```

Kotlin and Swift sources are compiled by the Android Gradle build and the
Xcode project generated by `tauri android|ios init`.

## Status

Android: implemented and exercised on an emulator. iOS: implemented; it
requires Xcode to compile and has not been built in this environment.
