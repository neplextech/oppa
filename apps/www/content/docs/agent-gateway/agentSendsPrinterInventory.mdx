          The agent sends a complete snapshot after the handshake and whenever a
          full refresh is needed. Include `correlationId` when this snapshot
          answers `server.request_printer_inventory`.

          `revision` is session-scoped. The first snapshot of a session may use
          any revision, including one lower than or equal to a revision from an
          earlier session, because agents may reset the counter on restart.
          Within one session the revision never decreases and advances whenever
          the inventory content changes; an identical snapshot may repeat the
          current revision. A server replaces its session inventory with each
          accepted snapshot.
