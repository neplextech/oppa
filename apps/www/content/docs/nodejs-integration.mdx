---
title: Node.js Integration
description:
  Connect a host-owned WebSocket transport to an OpenPrinter session.
---

Install the protocol and server packages plus the WebSocket transport
chosen by the host:

```bash
pnpm add @openprinter/protocol @openprinter/server ws
```

Create the protocol server and an explicitly local registry:

```ts
import { createServer } from 'node:http';
import { createOpenPrinterServer } from '@openprinter/server';
import { WebSocketServer } from 'ws';

const httpServer = createServer(app);
const webSockets = new WebSocketServer({
  noServer: true,
  clientTracking: false,
});
const localSessions = new Map();

const openPrinter = createOpenPrinterServer({
  brand: {
    name: 'Acme POS',
  },
  onAgentConnected({ agent, session }) {
    localSessions.set(agent.agentId, session);
  },
  onAgentDisconnected({ agent, session }) {
    if (localSessions.get(agent.agentId) === session) {
      localSessions.delete(agent.agentId);
    }
  },
  onJobReceived({ message }) {
    printJobs.markReceived(message.payload.jobId);
  },
  onJobSubmitted({ message }) {
    printJobs.markSubmitted(message.payload.jobId);
  },
  onJobFailed({ message }) {
    printJobs.markFailed(
      message.payload.jobId,
      message.payload.error,
    );
  },
});
```

The host owns upgrade routing and authentication. Once those complete,
adapt the accepted socket to the two transport callbacks:

```ts
function acceptAgentSocket(socket, identity) {
  const session = openPrinter.accept({
    identity,
    transport: {
      send(message) {
        return new Promise((resolve, reject) => {
          socket.send(message, (error) => {
            if (error) reject(error);
            else resolve();
          });
        });
      },
      close({ reason, detail }) {
        socket.close(webSocketCloseCode(reason), detail);
      },
    },
  });

  socket.on('message', (data, isBinary) => {
    if (isBinary) {
      socket.close(1003, 'Text messages required');
      void session.transportClosed({
        reason: 'transport-error',
      });
      return;
    }

    void session.receive(data.toString('utf8'));
  });

  socket.on('close', (_code, reason) => {
    void session.transportClosed({
      reason: 'peer-closed',
      detail: reason.toString('utf8'),
    });
  });

  socket.on('error', (error) => {
    void session.transportClosed({
      reason: 'transport-error',
      detail: error.name,
    });
  });
}
```

Your `upgrade` handler should:

1. match the OpenPrinter gateway path;
2. parse the authorization data expected by your application;
3. authenticate it with an explicit timeout;
4. reject invalid connections before upgrading;
5. call `webSockets.handleUpgrade`; and
6. pass the authenticated identity and socket to `acceptAgentSocket`.

Frameworks such as NestJS, Hono, Fastify, and Express may establish
the connection differently, but the `accept`/`receive` boundary
remains the same. No adapter needs to give the SDK control of its HTTP
server.

## Deliver a job

Only deliver a job already stored durably by your application:

```ts
const session = localSessions.get(agentId);

if (session === undefined) {
  await printJobs.keepQueued(job.id, 'agent-offline');
  return;
}

const result = await session.sendJob({
  jobId: job.id,
  idempotencyKey: job.idempotencyKey,
  printerId: job.printerId,
  createdAt: job.createdAt.toISOString(),
  document: job.document,
});

if (!result.ok) {
  await printJobs.keepQueued(job.id, result.reason);
}
```

This map is deliberately local. A Node cluster deployment must route
commands to the worker that owns the selected transport, for example
through application-managed IPC, RabbitMQ, Redis, or another
backplane. `@openprinter/server` does not synchronize workers.

Treat `job-received` as proof of durable local receipt and
`job-submitted` as proof that OPPA handed output to its selected
backend, not proof that paper was physically produced.
